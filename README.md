# HelpDesk-Interno
Sistema web para abertura, acompanhamento e gerenciamento de chamados internos, desenvolvido em Java com Spring Boot. A aplicação permite registrar solicitações, gerar protocolos, acompanhar o histórico de atendimento, alterar status, reabrir chamados e consultar a fila administrativa, utilizando API REST, validação de dados e banco H2 em memória.
